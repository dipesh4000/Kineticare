# Kineticare frontend

React/Vite UI with Privy email authentication and an Express API backed by Atlas.

From the project root, run npm install, configure .env and frontend/.env.local using .env.example, then npm run dev to start both servers. Frontend-only development uses npm run dev:frontend and needs the backend separately on port 3001.

Checks: npm test, npm run lint, npm run build. Firebase and emulator tests are removed.

[Current setup](../docs/PRIVY_ATLAS_SETUP.md).
